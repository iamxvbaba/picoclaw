# Metrics and Experiment Playbook

Use this reference for KPI design, funnel analysis, A/B planning, and launch validation.

## Metric Tree

1. Define one north-star metric.
2. Define 2-4 leading indicators that can move weekly.
3. Define guardrail metrics to control side effects.
4. Define baseline and target for each metric.

## Launch Metrics Checklist

- Is success metric directly tied to business objective?
- Are guardrails measurable in real time?
- Are definitions stable across data sources?
- Is there an owner for post-launch review?
