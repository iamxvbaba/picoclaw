# Prioritization and Roadmap

Use this reference for requirement prioritization, sequencing, and milestone planning.

## RICE Scoring

Use:

RICE = (Reach * Impact * Confidence) / Effort

Define each input explicitly:

- Reach: affected users or requests in a fixed period
- Impact: expected business/user value change
- Confidence: evidence quality (data, interviews, benchmarks)
- Effort: person-weeks or engineering complexity points

## Decision Rules

- Do now: high score, low dependency, clear strategic fit
- Do next: medium score, manageable dependency
- Hold: high uncertainty or missing prerequisite
- Drop: low value or strategy mismatch

## Roadmap Structure

Use Now / Next / Later:

- Now (0-1 quarter): committed delivery
- Next (1-2 quarters): validated direction
- Later (2+ quarters): directional bets
