# Creative Ideation Playbook

Use this reference when the task requires imagination, differentiation, or novel product bets.

## Output Pattern

For each idea, provide:

- Idea name:
- User problem solved:
- Why this is novel:
- Business impact hypothesis:
- Feasibility level:
- First low-cost validation:

## Idea Lenses

Generate ideas by combining at least 3 lenses:

1. Behavioral lens
- Habit loop design
- Social proof or multiplayer dynamics
- Commitment and reward mechanics

2. Business model lens
- New pricing logic
- New distribution model
- Ecosystem or marketplace extension

3. Technology lens
- AI-native workflow
- Automation-first experience
- Personalization at scale

4. Cross-industry lens
- Borrow a proven pattern from gaming, fintech, education, creator economy, or enterprise SaaS.

## Divergence Frameworks

### SCAMPER (quick prompts)

- Substitute: What can be replaced?
- Combine: What can be merged?
- Adapt: What from other categories can be adapted?
- Modify: What can be magnified or reduced?
- Put to another use: What new use case exists?
- Eliminate: What can be removed?
- Reverse: What if the order or ownership is reversed?

### Future-Back

- Assume a 3-year future user behavior shift.
- Design the product backward from that future.

### Constraint Flip

- If budget is near zero, what is the solution?
- If we need 10x growth, what must fundamentally change?

## Convergence Rules

After divergence, shortlist top 3 using:

- User value potential
- Strategic differentiation
- Delivery feasibility
- Learning speed

Always include one "safe bet" and one "bold bet".
